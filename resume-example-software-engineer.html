這份履歷為什麼好：四個關鍵

  1. 每一點都有數字：75%、40%、3 倍、50 萬筆——工程師的世界數字就是證據。沒有數字時，用規模（幾人團隊、多少流量）代替。
  2. 技能分類列出：不是雜亂一行「會 Python, Docker, AWS...」，而是「後端／資料庫／基礎設施」分層，一眼看出深度在哪。
  3. 由近到遠、近期寫最細：最近的職位 4 個列點，較久遠的 3 個。資歷越深，前面的經歷越能精簡。
  4. Side Project 證明熱情：1.2k stars、月訪 8,000 人是可驗證的影響力，比「對技術有熱情」有說服力一百倍。

工程師履歷常見錯誤

  • 列出所有碰過的語言但都不到實作等級——面試會被問爆，只列你能上工用的
  • 寫「負責系統開發與維護」——這是 job description 不是 achievement，寫你「做成了什麼」
  • 放照片、身高體重、婚姻狀況——科技業與外商不需要，浪費版面
  • 用表格或雙欄排版——部分求職系統（ATS）會打亂順序，看 ATS 格式指南
