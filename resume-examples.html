履歷格式怎麼寫：五個基本原則

  1. 一頁為原則：10 年內資歷一頁，超過再考慮兩頁。人資平均只看 6-7 秒。
  2. 標準欄位順序：姓名聯絡方式 → 學歷（新鮮人放前面）或經歷（有經驗放前面）→ 技能 → 作品/證照。
  3. 列點而非段落：每段經歷 2-4 個列點，一行一件事，動詞開頭（開發、導入、帶領、優化）。
  4. 數字說話：「提升效能」不如「將 API 回應時間從 800ms 降到 200ms（降低 75%）」。
  5. 針對職缺調整：同一份履歷投所有工作是最大錯誤。把職缺出現的關鍵字，對應到你真實的經歷上——用工具比對最快。

履歷必備欄位檢查清單

  • 姓名、Email、電話（市話可省）
  • 學歷：學校、科系、學位、年份（由近到遠）
  • 工作經歷：公司、職稱、任期、2-4 個量化列點
  • 技能：專業技能分類列出，避免「熟 Windows、Office」這種無效技能
  • 選配：作品連結（GitHub/作品集）、語言能力、證照
  • 照片：台灣部分企業習慣有照片，科技業與外商多半不需要——看產業慣例

常見問題

履歷一定要寫自傳嗎？

104 等平台的制式欄位有自傳欄，但多數科技業與外商更看重經歷列點。自傳控制在 300 字內，重點是「為什麼這個職缺適合你」，不是人生故事。

免費的履歷模板哪裡找？

本站的範例頁都是純文字格式，可以直接複製貼到 Word 或 Google Docs 使用，而且文字格式對求職系統（ATS）最友善，比花俏的設計模板更不容易被誤判。
