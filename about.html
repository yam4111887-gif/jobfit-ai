關於我們

Resume Preflight 是一個獨立開發的求職工具，2026 年成立於台灣。

為什麼做這個工具

多數求職者遇到的問題不是不夠優秀，而是履歷講的話和職缺要的話不同一套語言：你寫「負責後端開發」，職缺要的是「具備微服務架構經驗」；你有這個經驗，只是沒用對方的詞講出來。結果是履歷在第一關就被系統和人資略過，而你永遠不知道原因。

我們做的事很單純：把職缺和你的履歷放在一起，用對方的角度替你審一次，告訴你差在哪、怎麼補、怎麼講。

我們的原則

  • 不捏造。AI 只能重新組織你真實的經歷，不能無中生有。靠捏造得到的面試，一定會在面試中穿幫。
  • 不上傳。你的履歷只存在你自己的瀏覽器，AI 分析透過你自己設定的 API 金鑰進行，我們沒有伺服器存放任何人的資料。
  • 不綁平台。不管你的履歷在 104、Cake、LinkedIn 還是一份 Word 檔，複製貼上就能用。
  • 誠實的 ATS 觀點。履歷被刷掉的主因是資歷與關鍵字，不是格式。我們提供免費格式健檢幫你降低風險，但不販賣焦慮。

商業模式

目前完全免費：AI 功能使用你自己的 API 金鑰（BYOK），我們零伺服器成本，所以能永久免費。未來將推出 Pro 託管版（免設定、由我們提供 AI 額度，月費制）與學校、職涯中心的機構方案。免費版會繼續存在。
